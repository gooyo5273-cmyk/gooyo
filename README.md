# 주조 생산실적 분석

SAP에서 내려받은 생산실적 EXPORT 엑셀을 브라우저에서 분석하는 도구입니다.
`주조_생산실적_분석.html` 파일 하나만 있으면 되고, 설치가 필요 없으며 데이터는 PC 밖으로 나가지 않습니다.

## 사용법
1. `주조_생산실적_분석.html`을 크롬 또는 엣지로 엽니다.
2. SAP EXPORT 엑셀을 화면에 끌어다 놓습니다.
3. 기간·구분을 고르고 탭을 확인합니다. `엑셀 보고서 저장`으로 결과를 xlsx로 내려받습니다.

## 산식
- 집계 대상: 관리 품번 리스트(양품수율 파일 `불량수량` 시트)의 주조 품번
- 자공정 불량률 = 주조 불량 ÷ 주조 생산수량(양품+불량)
- 후공정 불량률 = 후공정 불량 ÷ 주조 생산수량 (리스트의 사상·가공·조립/출하 품번에 등록된 불량을 주조 품번에 귀속)
- 양품수율 = (주조 양품 − 후공정 불량) ÷ 주조 생산수량
- 목표 대비 실적: `주조생산계획수립` 파일의 주조팀 목표 대비 해당 월 양품 실적, 95~105% = 달성

## 수정·빌드
- `src/app.html` 화면과 계산 로직
- `src/master.json` 기본 내장 관리 품번 리스트
- `vendor/xlsx.full.min.js` SheetJS 0.18.5 (Apache-2.0)

```bash
python3 build.py
```
